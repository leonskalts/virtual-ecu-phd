# Exact implementation optimization after scientific freeze

The mathematical contract, reference and retained parameters were frozen before the optimized source was created. `clo_dsf_final_optimized.c` includes the frozen reference body with only two helper substitutions; decision logic is not forked or reimplemented.

The sparse combination helper enumerates the second mass's nonzero indices in increasing order, then traverses the first mass in the same increasing order as the generic core. Each nonzero product reaches the same intersection bin in exactly the same accumulation order. Validation, conflict threshold, flagged vacuous fallback and normalization still call the unchanged core semantics. This works for arbitrary generic mass functions, not only the final reachable focal sets. Complexity is O(2^n + f_a f_b) product traversal plus dense validation/normalization, where f_a/f_b are nonzero focal-set counts. The storage remains 64 entries per mass; memory was not reduced by this optimization.

The pignistic helper precomputes the immutable 31-subset encoding and logical cardinality tables. It retains the same increasing logical-subset accumulation order and floating divisions. There is no mass approximation, floating tolerance adjustment, new feature or change to the uncertainty/state output.

All 900 archived confirmation observation streams (1,080,900 samples) are replayed through reference and optimized code. The entire persistent state, including both masses, all output values, flags, counters, timestamps, observation history and diagnostic history, is bit-identical. Numeric tolerance used: zero. A separate randomized test checks generic dense/sparse Dempster and Yager combinations, in-place aliasing, total conflict and logical pignistic equivalence.

Build both with `make -f clo_dsf_final_optimized.mk`. The reference build remains `make -f clo_dsf_final.mk`; neither existing historical makefile was modified. Benchmark raw samples, means, medians, standard deviations, P95 and state/binary sizes are in `results/cross_layer_safety_v7_2_confirmation/benchmark/`. At least 31 paired/interleaved repetitions per mode and per scenario are measured after warmup. End-to-end measurements include raw CSV I/O, detector-specific diagnostic formatting, process creation and host scheduling. Final logs use 17 significant digits, historical candidates retain their original formatting. The result is host simulation overhead, not isolated core WCET or evidence that the implementation is lightweight.
