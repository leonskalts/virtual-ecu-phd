# CLOVER-CERT v7: two-world feasibility experiment

Start with [results.md](results.md). This is a reproducible **bounded component-model experiment**, not the final algorithm, a novelty claim, a full closed-loop ECU evaluation or physical safety certification. All 41 v6 unresolved findings remain intact.

From repository root, using existing Python standard library and gcc:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 research/clover_cert_v7/run_experiment.py
```

The runner verifies the imported v6/source snapshot, exhaustively regenerates finite model results, compiles/runs unchanged C components into v7, runs all new tests and checks preservation of 43,700 pre-existing files. It reads about 13.6 GB for preservation. Do not replace the baseline or import record to hide a changed checkout. It does not invoke Make, existing experiment runners, the GUI or production Python modules.

The ten fault-origin pairs are crossed independently over 66 fault realizations plus healthy per context. Two constant-input contexts, four observation views and three deadlines yield 240 pair checks and 24 frontier rows. Floats compare as exact binary32 bits. Capture selection changes; actual source acquisition remains 100 ms. No random seed is used.

## Supporting files

- `run_experiment.py`, `build_reports.py`: reproducible runner and report/manifest generator.
- `component_probe.c`, `compare_ecu.py`, `component_probe`, `build.log`: isolated C driver, compiler comparison, resulting executable and build output. No production file is modified.
- `modeled_executions.json`: model-generated observations and separate offline transition events.
- `actual_component_observations.json`, `ecu_comparison.json`: actual isolated C-component outputs, commands, hashes and all discrepancies.
- `conditional_positive_histories.json`, `oracle_summary.json`: every finite singleton history/assumption set and aggregate counts.
- `case_examples.json`: explicit stuck/pump and replay/drop/delay examples with histories; regenerated by the report builder.
- `v6_import_verification.json`: v6 read inventory/hashes, anchor recheck, original assumptions and all 41 findings.
- `tests.log`, `test_results.json`, `run_metadata.json`, `run.log`: actual tests and reproduction metadata.
- `workspace_baseline.json`, `preservation_report.json`, `git_status_before.txt`, `git_status_after.txt`: preservation evidence. Baseline excludes only `.git` and v7; Git HEAD is checked separately.

No physical positive certificate is emitted. Specific finite origins are conditional on the declared model and intact selected observations; absent/unverified physical contracts are not promoted by passing tests. Counts are combinatorial, not diagnostic-coverage probabilities.
